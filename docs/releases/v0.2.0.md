The first release of the DTM Demonstrator: DigiCert Device Trust Manager use cases end to end – timed against your DTM account, reproducible by copy & paste, and rolled back cleanly.

## Install

```bash
curl -fsSL https://github.com/danielstroehmann/dc-dtm-demonstrator/releases/latest/download/install.sh | sudo bash
```

Ubuntu Server 26.04 (amd64). The installer sets up the app behind its own TLS proxy with a login; running it again updates in place and keeps `.env` and `./data`.

## Use cases

- **Evergreen device certificates:** long-lived device IDs for the factory. A guide asks for the key generation (DTM or factory), single device or batch and – for factory keys – the protocol and authentication:
  - DTM-generated keys or factory CSRs as a batch, via API (measured, optional approval) or in the DTM web UI
  - single enrollment via REST, EST, CMPv2 or SCEP with an API key, a passcode or a factory certificate
- **Renewable device certificates:** one device is enrolled in the factory (EST or CMPv2) and renews in the field with a click, authenticated by the certificate it holds.
- **Passcode-bound device certificates:** the factory provisions one-time passcodes bound to each device's common name; the devices enroll in the field via EST or CMPv2. Single device or batch up to 100, both phases timed with statistics. Optional checks show what DTM enforces: a used passcode and a different common name are rejected.

## Highlights

- **Measured:** time per certificate / passcode, per minute and median; enrollment and passcode runs also estimate 1,000 devices.
- **Reproducible steps:** every DTM call and local step as curl, wget or PowerShell 7 – copy one step, a phase or the whole run as a script; IDs are taken from DTM's answers, every replay gets its own run name. Verified live for all use cases (bash).
- **Clean rollback:** one *Full rollback* per run in the runs list revokes the certificates and removes policies, credentials, the run's profile and the division. For web UI runs it also handles orders placed in the portal (waits for or rejects their batch jobs, finds certificates ordered under another policy).
- **Platforms:** `one.digicert.com` (US) and `one.nl.digicert.com` (NL); several connections and accounts per platform. Certificate profiles: one per run on NL (deleted by the rollback); shared per account on US, where DTM does not delete used profiles yet.
- **UI:** calm desktop UI in the docs.digicert.com look.

## Known limitations

- PowerShell snippets are untested on Windows.
- Lookups in the reproducible steps read the first 100 records of a list.
- DTM counts a rejected request against a one-time passcode – a device that sends a wrong CSR cannot enroll any more (reported DTM behaviour).
