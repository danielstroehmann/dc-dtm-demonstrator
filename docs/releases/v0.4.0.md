Demonstrator · Device Trust Manager v0.4.0: runs on **Windows 11, Windows Server 2022 and Windows Server 2025** and on **Linux arm64**.

## Install or update

Ubuntu Server 26.04 (x64 or arm64):

```bash
curl -fsSL https://github.com/danielstroehmann/dc-dtm-demonstrator/releases/latest/download/install.sh | sudo bash
```

Windows 11, Windows Server 2022 or 2025 (x64, Desktop Experience) – in an elevated PowerShell:

```powershell
irm https://github.com/danielstroehmann/dc-dtm-demonstrator/releases/latest/download/install.ps1 | iex
```

Running the installer again updates in place and keeps settings, password and data.

## New

- **Windows installer (`install.ps1`):** the same Linux stack in its own WSL 2 distro `dtm-demonstrator`.
  - On a fresh machine it enables WSL and restarts once. The installation continues at the next administrator logon, or when you run the command again.
  - It installs WSL from Microsoft's signed package and runs the Linux installer inside the distro.
  - It forwards ports 443 and 80 from the LAN and opens them in the Defender firewall: domain and private networks from any address, a public network from the local subnet only. On Windows 11 and Server 2025 it also adds rules to the Hyper-V firewall.
  - It starts the demonstrator at boot, with no logon needed.
  - `-Uninstall` removes it again.
- **Verified on fresh machines:** Windows Server 2025, Windows Server 2022 and Windows 11 Pro. On each, the installation, access from another machine on the LAN, a restart without any logon and, on Server 2025, an update.
- **Linux arm64:** the image is built for amd64 and arm64. The Ubuntu installer was already architecture-neutral.

## Changed

- The repository holds only the product: code, tests, installers, deployment files and release notes.

## Known limitations

- In a virtual machine, WSL 2 needs nested virtualisation from the host (e.g. Proxmox/KVM: CPU type `host`). Without it the installer stops with a hint.
- Windows Server Core is not supported.
- `-Uninstall` on Windows has not yet been verified on a real machine.
- The full installer on an arm64 machine has not been verified yet; the image and the stack are tested on arm64.
